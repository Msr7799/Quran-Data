🚀 أمثلة سريعة لاستخدام API

جرب هذه الأمثلة لبدء استخدام API القرآن الكريم:

📖 جلب جميع السور

GET /api/surahs

احصل على قائمة جميع السور مع معلوماتها الأساسية

📜 سورة محددة

GET /api/surah/1

احصل على بيانات كاملة لسورة محددة مع جميع آياتها

🔍 آية محددة

GET /api/verse/1/1

جلب بيانات آية محددة (رقم السورة/رقم الآية)

🎵 توقيت التلاوة

GET /api/timing/sudais/1

احصل على توقيت تلاوة آيات سورة للشيخ السديس

👥 جميع القراء الصوتيين

GET /api/reciters

قائمة شاملة بجميع القراء الصوتيين (133 قارئ)

👥 قراء التوقيت فقط

GET /api/timing/reciters

قائمة بقراء التوقيت فقط (4 قراء)

🎧 ملفات صوتية

GET /api/audio/1

روابط التسجيلات الصوتية للسور (133 قارئ)

🕌 آيات السجدة

GET /api/sajda

جميع آيات السجدة في القرآن الكريم (15 سجدة)

📄 صفحة القرآن

GET /api/pages/2/1

معلومات صفحة القرآن لآية محددة (604 صفحة)

📚 جزء من القرآن

GET /api/juz/1

معلومات جزء محدد من القرآن (30 جزء)

🖼️ صور صفحات القرآن

GET /data/quran_image/1.png

صور عالية الجودة لصفحات المصحف الشريف

📋 مرجع API

GET /api/api-reference

مرجع شامل لجميع endpoints والإحصائيات

🔍 البحث في التوقيتات

GET /api/timing/sudais/surahs

البحث في السور المتوفرة لقارئ توقيت محدد
