🖼️ صور القراء وأسماء السور

🚀 أمثلة سريعة لاستخدام API

جرب هذه الأمثلة لبدء استخدام API القرآن الكريم:

📖 جلب جميع السور

GET /api/surahs

احصل على قائمة جميع السور مع معلوماتها الأساسية

📜 سورة محددة

GET /api/surah/1

احصل على بيانات كاملة لسورة محددة مع جميع آياتها

🔍 آية محددة

GET /api/verse/1/1

جلب بيانات آية محددة (رقم السورة/رقم الآية)

🎵 توقيت التلاوة

GET /api/timing/1/1

احصل على توقيت آيات سورة كاملة لقارئ برقم mp3quran

👥 جميع القراء الصوتيين

GET /api/reciters

قائمة شاملة بجميع القراء الصوتيين (133 قارئ)

👥 قراء التوقيت فقط

GET /api/timing/reciters

قائمة بقراء التوقيت المتاحين (96 قارئ حفص)

🎧 ملفات صوتية

GET /api/audio/1

روابط التسجيلات الصوتية للسور (133 قارئ)

🕌 آيات السجدة

GET /api/sajda

جميع آيات السجدة في القرآن الكريم (15 سجدة)

📄 صفحة القرآن

GET /api/pages/2/1

معلومات صفحة القرآن لآية محددة (604 صفحة)

📚 جزء من القرآن

GET /api/juz/1

معلومات جزء محدد من القرآن (30 جزء)

🖼️ صور صفحات القرآن

GET /data/quran_image/1.png

صور عالية الجودة لصفحات المصحف الشريف

📋 مرجع API

GET /api/api-reference

مرجع شامل لجميع endpoints والإحصائيات

🔍 سور قارئ التوقيت

GET /api/timing/1/surahs

البحث في السور المتوفرة لقارئ توقيت محدد

🔎 بحث توقيت آية

GET /api/timing/search?reciter=1&surah=1&verse=1

البحث في التوقيتات حسب القارئ والسورة والآية

🎙️ قراء آية-بآية

GET /api/ayah-audio/reciters

قراء ملف ayahBayah.json مع روابط الجودات المتاحة

🎧 صوت آية واحدة

GET /api/ayah-audio/1/1/1?bitrate=32

يبني رابط MP3 لآية محددة مثل 001001.mp3

🖼️ صور القراء مع IDs

GET /api/reciter-images

يربط ID القارئ مباشرة برقم الصورة، مثال: 68 ← 068-عبدالرحمن السديس.jpg.

🕌 صور أسماء السور

GET /api/surah-names

يعيد أسماء السور وروابط SVG من data/suwer-name، مثل /data/suwer-name/001.svg.

🎙️ قراء التتبع آية بآية

GET /api/ayah-bayah/reciters

قائمة القراء المتاح لهم Surah-by-Surah أو Ayah-by-Ayah مع عدد السور والآيات والتوقيتات.

👤 تفاصيل قارئ التتبع

GET /api/ayah-bayah/reciter/68

مثال عبدالرحمن السديس (ID 68): بيانات القارئ، الصورة، نوع التسجيل والسور المتاحة.

▶️ سورة كاملة مع التتبع

GET /api/ayah-bayah/68/1

مثال الفاتحة بصوت السديس: رابط تسجيل السورة وتوقيت كل آية/كلمة حسب نوع المصدر.

⏱️ آية محددة مع توقيتها

GET /api/ayah-bayah/68/1/1

مثال الآية 1 من الفاتحة: يرجع timestamp أو audio_url وword segments لتفعيل التتبع أثناء التشغيل.

🧪 أمثلة القراء والصور والتتبع آية بآية

أمثلة جاهزة للنسخ والتجربة للإضافات الجديدة. يمكن استخدام ID القارئ الأساسي مثل 68، كما يمكن استخدام رقم مصدر QUL مثل 959 و960 للتسجيلات Ayah-by-Ayah.

القارئ ID QUL النوع التتبع مثال
بندر بليله29—Surah-by-Surah✅ 6236 آية/api/ayah-bayah/29/1/1
سعود الشريم46960Ayah-by-Ayah✅ 6236 آية/api/ayah-bayah/960/1/1
عبدالرحمن السديس68—Surah-by-Surah✅ 6236 آية/api/ayah-bayah/68/1/1
عبدالله عواد الجهني82—Surah-by-Surah✅ 6236 آية/api/ayah-bayah/82/1/1
علي الحذيفي90—Surah-by-Surah⚠️ segments.json فارغ/api/ayah-bayah/90/1
ماهر المعيقلي — المرتل101—Surah-by-Surah✅ 6236 آية/api/ayah-bayah/101/1/1
محمد صديق المنشاوي — المرتل112959Ayah-by-Ayah✅ 6236 آية/api/ayah-bayah/959/1/1
مشاري العفاسي131—Surah-by-Surah✅ 6236 آية/api/ayah-bayah/131/1/1
ياسر الدوسري152—Surah-by-Surah✅ 6236 آية/api/ayah-bayah/152/1/1

1) قائمة القراء مع الصور

GET /api/reciter-images
fetch('/api/reciter-images')
  .then(r => r.json())
  .then(console.log);

الربط مباشر: reciter.id → بادئة الصورة NNN. مثال ID 68 يستخدم ملف 068-عبدالرحمن السديس.jpg.

2) صور أسماء السور

GET /api/surah-names
// مثال للصورة الأولى
/data/suwer-name/001.svg

الاستجابة تجمع اسم السورة العربي/الإنجليزي مع image_url لملف SVG.

3) القراء الذين لديهم بيانات تتبع

GET /api/ayah-bayah/reciters
curl https://quran-api-msr.vercel.app/api/ayah-bayah/reciters

يعرض النوع surah-by-surah أو ayah-by-ayah، وعدد السور والآيات والـ word segments.

4) السديس — الفاتحة مع التتبع

GET /api/ayah-bayah/68/1
{
  "recitation_type": "surah-by-surah",
  "surah_number": 1,
  "audio": {
    "surah_number": 1,
    "audio_url": "https://audio-cdn.tarteel.ai/quran/surah/abdulrahmanAlSudais/murattal/mp3/001.mp3",
    "duration": 34
  },
  "segments": [
    {
      "key": "1:1",
      "timestamp_from": 0,
      "timestamp_to": 2889,
      "duration_ms": 2889,
      "segments": [[1,0,830],[2,880,1310],[3,1360,2270],[4,2320,2889]]
    }
  ]
}

استخدم timestamp_from وtimestamp_to لمتابعة الآية داخل ملف السورة، ومصفوفة segments لمتابعة الكلمات.

5) المنشاوي — آية بصوت مستقل

GET /api/ayah-bayah/959/1/1
{
  "recitation_type": "ayah-by-ayah",
  "surah_number": 1,
  "verse_number": 1,
  "ayah_audio_url": "https://audio-cdn.tarteel.ai/quran/minshawyMurattal/001001.mp3",
  "segment": {
    "key": "1:1",
    "segments": [[1,0,840],[2,1040,1440],[3,2200,2560],[4,2880,4920]]
  }
}

959 هو رقم مصدر QUL الموجود في اسم ملف المنشاوي، ويقبل الـ API هذا الرقم مباشرة.

6) سعود الشريم — آية بآية

GET /api/ayah-bayah/960/1/1
const data = await fetch('/api/ayah-bayah/960/1/1')
  .then(r => r.json());

audio.src = data.data.ayah_audio_url;
// 1:1 => https://audio-cdn.tarteel.ai/quran/saudAlShuraim/001001.mp3
// segments => [[1,0,560],[2,720,1040],[3,1600,1920],[4,2080,2800]]

960 هو رقم مصدر QUL للشريم. يمكن أيضًا استعمال ID القارئ الأساسي عندما يكون موجودًا في كتالوج surah_1.json.
