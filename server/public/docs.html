🚀 أمثلة سريعة لاستخدام API

جرب هذه الأمثلة لبدء استخدام API القرآن الكريم:

📖 جلب سورة الفاتحة

GET /api/surah/1

احصل على بيانات كاملة لسورة الفاتحة مع جميع الآيات

🎵 توقيت الفاتحة للسديس

GET /api/timing/sudais/1

احصل على توقيت تلاوة آيات سورة الفاتحة للشيخ السديس

👥 جميع القراء

GET /api/timing/reciters

قائمة بجميع القراء المتاحين مع إحصائيات التوقيت

🔍 آية محددة

GET /api/verse/1/1

جلب بيانات آية محددة (السورة/الآية)

🎧 ملفات صوتية

GET /api/audio/1

روابط التسجيلات الصوتية للسور

🕋 آيات السجدة

GET /api/sajda

جميع آيات السجدة في القرآن الكريم

📦 تحميل قواعد البيانات

حمل قواعد البيانات بصيغ مختلفة لاستخدامها في مشاريعك
